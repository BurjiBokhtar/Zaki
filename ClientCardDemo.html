ℹ️ О компоненте

Унифицированная карточка клиента объединяет две разных реализации из разделов "Клиенты" и "Контракты" в один переиспользуемый компонент с поддержкой трёх вариантов отображения.

✨ Три варианта

Компактный, Развёрнутый, Современный

📱 Адаптивный

Автоматическое переключение при изменении размера экрана

🌙 Тёмный режим

Полная поддержка prefers-color-scheme

⚡ Синхронизация

updateData() для обновления без перезагрузки

🎨 Кастомизируемый

CSS переменные для изменения цветов

Плавные переходы и эффекты

💻 Пример использования

Вставьте этот код в ваш проект:

// Создать карточку const card = new ClientCard('container', { variant: 'auto', // 'compact', 'expanded', 'modern', или 'auto' data: { name: 'Давлатхочаева Тамано Аломидиновна', initials: 'ДА', passport: 'AD1228834', address: 'Блок А / Дарсметохон 2, №10-3', debt: 13698, issued: 21300, received: 21300, progress: 64, lastPayments: [ { date: '30/06/2026', amount: 2400, status: 'Чес' }, { date: '20/05/2026', amount: 1000 } ] }, callbacks: { payment: (data) => handlePayment(data), history: (data) => showHistory(data) } }); // Обновить данные card.updateData({ debt: 10000, progress: 75 });

📂 Файлы компонента

Три файла необходимо скопировать в ваш проект:

  • ClientCardComponent.js — логика компонента (3.5 KB)
  • ClientCardComponent.css — все стили для трёх вариантов (15 KB)
  • CLIENT_CARD_INTEGRATION.md — документация с примерами

Компонент не имеет зависимостей и работает с ванильным JavaScript

🔄 Миграция со старого кода

Если у вас есть две отдельные реализации карточки клиента:

// БЫЛО (два разных компонента): function renderClientFromList() { /* ... */ } function renderClientFromContract() { /* ... */ } // СТАЛО (один унифицированный компонент): function renderClient(variant = 'auto') { new ClientCard('container', { variant: variant, data: clientData }); }

Просто замените оба старых рендерера на новый компонент с параметром variant.
