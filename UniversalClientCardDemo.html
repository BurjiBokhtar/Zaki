Красивые цветные полосы для быстрого анализа

💻 Как использовать

Подключите файлы и создайте карточку:

// 1. Подключить в index.html <link rel="stylesheet" href="/UniversalClientCard.css"> <script src="/UniversalClientCard.js"></script> // 2. Создать карточку const card = new UniversalClientCard('container-id', { data: { // Информация о клиенте clientName: 'Давлатхочаева Тамано Аломидиновна', clientInitials: 'ДА', passport: 'AD1228834', birthDate: '1990-07-04', address: 'Блок А / Дарсметохон 2, №10-3', apartment: 'Кв. №10-3', // Финансы issued: 21300, // Выданно received: 21300, // Получено debt: 0, // Остаток долга // Платежи payments: [ { date: '30/06/2026', amount: 2400, status: 'paid' }, { date: '20/05/2026', amount: 1000, status: 'paid' } ], // Дополнительно status: '✓ Активный', lastUpdate: 'Обновлено сегодня' }, callbacks: { payment: (data) => console.log('Оплата', data), history: (data) => console.log('История', data), contract: (data) => console.log('Договор', data), print: (data) => window.print() } }); // 3. Обновить данные (без перезагрузки) card.updateData({ debt: 5000, received: 16300 });

🗂️ Структура данных

{ // ИНФОРМАЦИЯ О КЛИЕНТЕ clientName: 'ФИО', // обязательно clientInitials: 'АБ', // 1-2 символа для аватара passport: 'AD1228834', // номер паспорта (опционально) birthDate: '1990-07-04', // дата рождения (опционально) address: 'Адрес', // адрес (опционально) apartment: 'Кв. №10-3', // квартира (опционально) // ФИНАНСОВЫЕ ПОКАЗАТЕЛИ issued: 21300, // Выданно всего (USD) received: 21300, // Получено платежей (USD) debt: 0, // Остаток долга (USD) // ПЛАТЕЖИ payments: [ // Массив платежей { date: '30/06/2026', // дата платежа amount: 2400, // сумма currency: 'USD', // валюта (опционально) status: 'paid' // 'paid', 'pending' } ], // ИСТОРИЯ (опционально) paymentHistory: [ { icon: '✓', // эмодзи или иконка title: 'Оплачено 2400', date: '30/06/2026', amount: 2400 } ], // ДОПОЛНИТЕЛЬНО status: '✓ Активный', // статус клиента lastUpdate: 'Обновлено сегодня' // последнее обновление }

🎯 Callbacks (обработчики событий)

Все доступные обработчики:

callbacks: { payment: (data) => { // Нажата кнопка "Быстрая опалата" // data содержит всю информацию карточки }, history: (data) => { // Нажата кнопка "История" // Показать полную историю платежей }, contract: (data) => { // Нажата кнопка "Договор" // Показать/скачать договор }, print: (data) => { // Нажата кнопка "Печать" // Вызовите window.print() }, 'show-all-payments': (data) => { // Нажата кнопка "Показать все платежи" }, 'edit-payment': (data) => { // Нажата иконка редактирования на строке платежа }, 'select-payment': (payment, index) => { // Кликнул на строку платежа } }
