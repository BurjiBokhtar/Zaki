Подключите Supabase
Вставьте ключи из вашего Supabase проекта. Они сохранятся в браузере — вводить один раз.
1
Создайте проект на Supabase
Зайдите на supabase.com → New Project → дождитесь создания (~2 мин)
2
Запустите SQL схему
В Supabase → SQL Editor → вставьте содержимое файла supabase_schema.sql → Run
3
Создайте пользователей
Supabase → Authentication → Users → Add User → создайте аккаунты для бухгалтера, снабженцев, директора
4
Скопируйте ключи
Supabase → Settings → API → скопируйте Project URL и anon public key
💡 Ключи хранятся только в вашем браузере (localStorage). Никуда не передаются.
После сохранения эта страница больше не появится.
